# Python-Algo-Math-Toolbox
Résolution de 134 défis algorithmiques sur la plateforme France-IOI (structures de contrôle, tableaux, chaînes de caractères, optimisation) et développement d'utilitaires exécutables en Python dédiés à l'arithmétique modulaire et à la théorie des nombres (tests de primalité, décomposition en facteurs premiers, calcul de PGCD/PPCM).
### Technologies :
Python, Algorithmique, Arithmétique.
